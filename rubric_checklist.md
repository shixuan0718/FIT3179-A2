# Rubric checklist before submission

- [ ] Keep the original hand-drawn sketch; do not replace it with a digitally generated sketch.
- [x] Single scrollable web page.
- [x] 11 charts (>10 required for high bands).
- [x] 4 map idioms (minimum 3 required).
- [x] At least 8 advanced idioms: 4 maps, treemap, parallel coordinates, radial bar, heatmap, streamgraph.
- [x] All charts are Vega or Vega-Lite.
- [x] Four clearly separated story sections.
- [x] Responsive layout with no intended horizontal scrolling on a small laptop.
- [x] Non-standard topic-appropriate display font + readable body font.
- [x] Extensive narrative annotations outside charts plus labels/tooltips within charts.
- [x] Metadata, author, date, data limitations and AI acknowledgement included.
- [ ] Push to GitHub and enable GitHub Pages.
- [ ] Check every chart and JSON URL in incognito mode.
- [ ] Put the public visualisation URL into Part A of the Moodle template.
- [ ] Upload/link the hand-drawn sketch PDF in Part C.
- [ ] Paste a full-size screenshot into Part D.
- [ ] Practise explaining why each idiom was chosen and the limitations listed in the footer.
